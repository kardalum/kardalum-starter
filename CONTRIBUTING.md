# Contributing

Thank you for helping. This repository holds Kardalum's examples and its
community issue tracker.

## Where to report

- **A bug or a feature request**: open an [issue](../../issues), using the
  template that fits.
- **A question or an idea**: start a [discussion](../../discussions).
- **A plugin toolchain problem**: the
  [kardalum-devkit issues](https://github.com/kardalum/kardalum-devkit/issues).
- **A security vulnerability**: never in public. Follow
  [SECURITY.md](SECURITY.md).

## Pull requests

Improvements to the examples and to this README are welcome as pull
requests. Every commit must carry a `Signed-off-by:` line, certifying the
[Developer Certificate of Origin](https://developercertificate.org/): you
wrote the change, or have the right to submit it under this repository's
license. `git commit -s` adds the line for you. A check on every pull
request refuses commits without it.

## The product itself

Kardalum's own source is developed in a private repository, so changes
to the CMS are proposed here as issues rather than as pull requests. The
packages it publishes are on npm under the `@kardalum` scope, licensed
Apache-2.0, and free to use.
